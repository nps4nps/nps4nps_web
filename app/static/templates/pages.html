Accessing the data

How can I retrieve data?

The information published as Nanopublications can be queried programmatically using SPARQL. This allows you to retrieve specific information, combine data from different sources, and integrate results into your own workflows.

However, writing and running SPARQL queries requires some technical knowledge and is not necessarily user-friendly. To make the data more accessible, we provide visual applications that let you explore selected information interactively, without having to write queries yourself.

SPARQL endpoint

If you are familiar with SPARQL, you can query the nanopublication data directly through our SPARQL endpoint. This is the most flexible way to retrieve data, but it requires knowledge of the query language and the underlying data structure.
